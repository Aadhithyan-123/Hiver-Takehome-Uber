Quickstart & Local Reproduction (< 15 Seconds)

Shipped with sample dataset (data/sample_data.csv) and deterministic offline engine

# 1. Clone repository & install dependencies
git clone https://github.com/your-username/hiver-takehome-uber.git
cd hiver-takehome-uber
pip install -r requirements.txt

# 2. Run the complete 7-stage pipeline in < 15 seconds
./run_pipeline.sh

# 3. Run with CLI flags
python3 src/pipeline.py --brand uber --sample
python3 src/evaluate.py --golden_set data/processed/golden_set.jsonl

# 4. Launch interactive terminal CLI for live reviewer testing
python3 src/demo_cli.py
